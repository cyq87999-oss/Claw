# I2V Prompt Templates（完整范例）

Each example applies the 10-element skeleton + vertical logic. Use as the canonical
input→output pattern before writing new prompts. Continuity shots share 首尾帧.

## Example A — 国风漫剧 · 单镜（拔剑特写）

**Input**: 参考图 = 黑发女子墨袍持剑静立；风格国风漫剧厚涂；情绪冷冽；竖屏。

**Output**

- **Shot**: 镜 1
- **Prompt (CN)**:
  一位黑发及腰、左眼角泪痣的年轻女子，身着墨色交领长袍、袖口银纹，正对镜头立于画面中下（主体锁定）；右手缓缓握剑柄由鞘中抽出，动作匀速小幅（动作描述）；镜头从胸口缓慢上摇至面部特写（镜头运动）；特写，面部占画面 70%，头顶留白，居中（景别/构图）；冷蓝逆光，雨夜，湿地面霓虹反射，高对比（光影氛围）；国风漫剧、厚涂笔触、电影感、细节丰富、统一美术风格（风格一致性）；本镜 4 秒，前 1 秒给眼神特写钩子（节奏与时长）；前景雨丝虚化，人物中景清晰，不穿模（空间关系）；起始帧人物静立扶剑，结束帧剑已出鞘横于胸前抬眼（首尾帧约束）；排除模糊、变形、多余肢体、字幕水印、低质量（负面提示词）。
- **Negative (CN)**: 模糊、变形、手指异常、面部畸变、字幕、水印、风格跳变、穿模、过曝、抽帧。
- **Continuity**: 以参考图为首帧。

## Example B — 3D 渲染 · 序列（跃起躲避 → 落地反击）

**Input**: 角色 = 机甲少年；风格 3D 渲染虚幻引擎；竖屏快节奏序列。

**Shot 1**
- 一位银发机甲少年，身着深蓝装甲、肩甲发光纹路，居画面中下（主体锁定）；向后猛地腾空跃起，纵向大幅，躲避地裂（动作描述）；镜头随主体轻微上移跟拍（镜头运动）；中景，主体居中，头顶留白（景别/构图）；冷色调顶光，废墟黄昏，尘暴（光影氛围）；3D 渲染、虚幻引擎风格、光线追踪、电影级调色（风格一致性）；本镜 3 秒快切（节奏与时长）；前景碎石虚化，背景裂谷景深（空间关系）；起始帧站立，结束帧跃起至最高点（首尾帧约束）；排除模糊、变形、穿模、低质量（负面提示词）。

**Shot 2（接 Shot 1 结束帧）**
- 同一银发机甲少年，装甲与发光纹路不变（主体锁定）；自最高点俯冲落地，右拳砸地向前的冲击波，快速大幅（动作描述）；镜头自上方下摇至落地特写（镜头运动）；近景，主体居中偏右三分线（景别/构图）；暖橙爆炸光，尘暴漫射（光影氛围）；3D 渲染、虚幻引擎风格、光线追踪、电影级调色（风格一致性）；本镜 3 秒（节奏与时长）；前景尘幕虚化，不遮挡主体脸（空间关系）；起始帧跃起最高点，结束帧单膝触地拳击地面（首尾帧约束）；排除模糊、变形、穿模、低质量（负面提示词）。

## Example C — 厚涂 · 表情钩子首镜

**Input**: 古风男子；欲做滑屏短视频开篇强情绪；竖屏。

- **Shot**: 镜 1（开篇钩子）
- 一位中年古风男子，灰白鬓发、左颊刀疤，玄衣金扣，正对镜头占画面中心（主体锁定）；骤然睁眼、瞳孔收缩、微微后仰，表情惊怒（动作描述）；镜头极缓推近至双眼特写（镜头运动）；特写，双眼居中安全区，头顶留白（景别/构图）；顶光冷白，室内烛影摇曳（光影氛围）；厚涂、电影感、统一美术风格（风格一致性）；本镜 2.5 秒，开篇即给表情特写（节奏与时长）；前景烛火虚化光斑（空间关系）；无强制首尾帧，以参考图为首帧（首尾帧约束）；排除模糊、变形、字幕水印、低质量（负面提示词）。
