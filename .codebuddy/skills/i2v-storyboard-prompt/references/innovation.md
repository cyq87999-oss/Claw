# 灵活运用与跨界创新 · 资源池与方法论

本文档是 `i2v-storyboard-prompt` 技能的「创新层」。当目标是**不复制模板、而是灵活组合现有资源、杂交出新的运镜与视觉效果**时加载本文件。它把词库 / 实战范例 / 模板拆成两类可组合素材（运镜骨架 + 视觉特效），并给出「融合 → 进化」两步走法。

---

## 一、实操铁律（从截图范例总结，必须优先遵守）

1. **角色一致性优先**：全局设定一次性写全角色外观特征，不要在分镜里修改人物描述，防止 AI 换脸、改服装。→ 用法：【基础设定】/【角色卡】只写一次，后续片段只引用变量，不复述长相。
2. **运镜描述要精准**：不要只写“镜头移动”，要用专业运镜词（同步平移环绕、极速变焦、跟焦、环绕仰拍、倒退跟拍），解决空间反向、镜头旋转崩坏问题。参考驼客那张的「摄影机位与空间绝对指令」写法——把轨迹按秒焊死角度。
3. **动作拆分粒度**：每段镜头**单核心动作**，不要在同一个时间切片塞过多连续动作，否则动作崩坏。
4. **音效和画面绑定**：每一条分镜同步写音效，实现音画同步，这是 Seedance 2.0 的优势。声音行单独成行、用拟声词 + “——”拉长（嗡——/嘶——/咔嚓！）。
5. **分层调试策略**：先跑【全局设定 + 前 3 个分镜】测试画风角色，没问题再追加剩余镜头，不要一次性生成 20s 长镜头。

## 三、融合机制（本地组合，确定性产出）

**骨架叠加（默认）**：以运镜为骨，在其节奏高潮节点（约骨架 60% 处）触发特效并物理耦合。
> 例：以「同步平移环绕·驼客」为运镜骨架，在环绕至 270°（左侧）节点触发「马赫锥冲击云」：黑火药引爆，尾部喷发白色奇爆云冲击波，运镜推进到该节点时特效同步达峰值，单镜头内完成「运动 + 爆发」一体。

**多骨架串联**：多条运镜按时间码串联（A 0-3s → B 3-7s），每个切换点用一条特效（如玻璃碎裂）做视觉过场。

**随机灵感碰撞**：从全库随机抽一对「运镜 × 特效」杂交，专用于打破思维定式蹦新点子。

**可直接使用提示词片段** = 基础场景 + 运镜骨架句（用“；”连） + “，画面中” + 特效描述（用“，”连） + “。电影级画质，OC 渲染，8K 超高清。”

## 四、AI 跨界创新（进化，产出 1+1>2）

把所选素材连同基础场景喂给 OpenAI 兼容模型，让它**杂交出全新运镜 + 视觉特效组合**（不是简单拼接，而是把 A 的运镜轨迹与 B 的特效物理耦合、在某秒触发连锁反应）。

**输入**：基础场景 + 所选运镜资源（名称+骨架）+ 所选视觉特效资源（名称+效果）。
**系统词（system）**：你是顶尖的运镜与视觉特效创新师……请跨界杂交出一种全新的运镜+视觉特效组合，产生 1+1>2 的新效果。输出 JSON。
**输出 JSON 键**：`name`（酷名）、`camera`（新运镜，含时间码与角度）、`vfx`（新特效，含触发节点与物理）、`fusion`（一句话耦合机制）、`prompt`（可直接使用的完整提示词片段，中文）。
**注意**：需用户在网页「AI 联网设置」填 Key；无 Key 时走第三节的本地融合即可。

## 五、主流提示词结构速查（何时用哪种）

- **10 要素**：单镜通用，最稳。主体锁定/动作/镜头运动/景别构图/光影/风格/节奏/空间/首尾帧/负面。
- **打斗版切片**：含台词、角色对的动作戏。基础风格锚定 + 三切片（0-3s 对峙 / 中段交手 / 高潮绝杀），每段含镜头/场景/A/B/动作/特效/音频。
- **基础设定 + 画面内容（双层）**：多片段、需角色/场景绝对一致。基础设定(+氛围画质)只写一次锁外观，画面内容每段只写变量（景别/构图/运镜/动作）。
- **Seedance 2.0 时间码**：每镜「镜头 0N【起-止秒】景别 / 运镜」+「画面视图：…」+「声音设计：…」，多镜时间码递进。
- **实战范例写法（4 种）**：编号时间码列表（30s 纯画面）/ 开头总风格段+[时长Xs]段落（长镜头武侠）/ 段落式总时长+旁白（剧情短片）/ 每镜时长+背景音乐音效+「接到上一镜头」衔接（变装搞笑）。

## 六、实战范例索引（各教一招）

- 影杀·瞬狱 → 分段时间码 + 音效 + 字幕收尾标准模板。
- 血池虎先锋 → 两段式台词驱动打斗；黑白仅留红瞳的视觉焦点写法。
- 天马迎新 → 以图为首帧（图生视频），首句写「从参考图起始」+ 延续参考图色彩。
- 黑白猫武士 vs 广智 → 30s 八场景、参考图锁角（image_2.png / input_file_0.png）。
- 索道飞梭 → 一镜到底极限运镜，重复「（一镜到底！）」。
- 驼客 → 同步平移环绕，运镜轨迹按度数焊死（防方向反向）。
