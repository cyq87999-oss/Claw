# 动作 / 电影感分镜描述词体系（Action / Cinematic Storyboard）

适用：即梦 / 可灵 / Wan / Runway / Sora 等图生视频、文生视频。本包解决「画面描述怎么写才专业」——
补 `prompt-playbook.md` 的「词库」短板，给出**造句结构 + 节奏 + 进阶技巧 + 一场完整高潮戏范例**。
生成时把下列词串与句式嵌入 10 要素的「动作描述 / 镜头运动 / 景别构图 / 光影氛围」即可。

---

## 一、核心要素：每个描述必备的「弹药」

### 1. 镜头运动
- **推 / 拉**：镜头急速推向角色惊恐的双眼 / 镜头从爆炸全景拉出，展现混乱的街道。
- **摇 / 移**：镜头跟随摩托车在车流中高速穿梭 / 横摇扫过一排蓄势待发的特工。
- **跟**：手持镜头紧跟主角奔跑，呼吸感强烈。
- **升 / 降**：无人机视角从地面两人对峙升至城市夜空。
- **固定**：稳定、冷静的旁观视角，突出动作爆发瞬间。

### 2. 景别变化
- **大远景**：展现环境规模（车队行驶在荒漠）。
- **全景**：看清人物全身及周围环境（两人在屋顶对峙）。
- **中景**：腰部以上，聚焦人物互动和动作（打斗中的攻防）。
- **近景**：胸部以上，捕捉面部表情和紧张情绪。
- **特写**：决定性细节（扣动扳机的手指、飞溅的汗水、定时器数字）。

### 3. 动态与节奏关键词
- **速度感**：疾驰、呼啸、电光石火、残影、模糊、瞬间。
- **力量感**：爆裂、粉碎、冲击、震颤、撼动、摧枯拉朽。
- **紧张感**：骤然、猝不及防、千钧一发、间不容发。
- **节奏感**：紧接着、与此同时、旋即、一连串、缓慢地…突然！

### 4. 视听氛围词
- **视觉**：火光冲天、玻璃四溅、尘土飞扬、慢动作、子弹时间、冷色调 / 暖色调。
- **听觉**：金属刮擦、引擎轰鸣、寂静无声、心跳声放大、由远及近的警笛。
- **感觉**：压迫感、窒息感、眩晕感、肾上腺飙升。

## 二、万能结构模板

【镜头号（可选）】+【景别】+【镜头运动/角度】+【核心动作/事件】+【情绪/氛围/细节特写】+【（可加）音效/转场】

- **示例 1（追车戏）**
  - 中景-跟拍 主角驾驶肌肉车猛打方向盘，轮胎在路面擦出刺耳尖啸与白烟，表情决绝。
  - 特写 后视镜中，反派车辆的车头急速放大，灯光晃眼。
  - 全景-俯拍 两辆车一前一后，蛇形穿梭在停滞的车流中，如同金属鲨鱼。
- **示例 2（近身格斗）**
  - 近景 反派挥拳袭来，带起风声。主角瞬间低头躲过，发丝扬起。
  - 特写-慢动作 主角的肘击精准命中对手肋部，汗水从下巴震飞。
  - 全景-仰拍 反派应声撞碎木桌，碎片四溅，尘土在光束中飞扬。

## 三、进阶技巧：让你脱颖而出

1. **对比与静默**：「一切声响消失，只听见自己的心跳。下一秒，玻璃轰然炸裂，黑影破窗而入！」（静与动的对比）
2. **主观视角**：「POV 视角（主角视点），天旋地转，地面快速逼近——是正从高楼坠落！」（增强代入感）
3. **比喻与通感**：「子弹如蜂群般呼啸掠过。」「爆炸的火光将他的剪影吞没，热浪舔舐着镜头。」
4. **时间操控**
   - 子弹时间：「时间仿佛凝固。子弹旋转着穿过空气，轨迹清晰可见，擦过主角的脸颊。」
   - 快速剪辑：「一连串不到一秒的快速闪回：沾血的照片、倒计时、爱人的脸。他眼神骤然坚定。」

## 四、实战示例：组合生成一场高潮戏（最终决战 · 仓库枪战与肉搏）

1. 【大远景-俯拍】 昏黄的仓库，集装箱如迷宫。两道手电光束猝然交错，枪声撕破寂静。
2. 【中景-跟拍】 主角贴靠集装箱疾跑，子弹「砰砰砰」在身侧溅起一连串火花碎屑。
3. 【特写】 主角呼吸急促，快速更换弹夹，金属卡榫声清脆。
4. 【全景-慢动作】 反派从高处跃下，主角同时仰身滑铲，两人擦身而过的瞬间，各自开枪。空弹壳晶莹地悬浮在空中。
5. 【近景】 手枪子弹打空。两人目光对撞，同时弃枪，冲向对方。
6. 【中景-快速切换】 一连串凶狠、写实的近身格斗：关节技、重拳、踢击。闷响与喘息交织。
7. 【特写】 主角被扼住咽喉，手艰难地摸索，终于抓住一根生锈的铁钎。
8. 【全景-固定镜头】 主角用尽最后力气，反手刺出。动作骤然停止。反派僵住，缓缓倒地。
9. 【近景-升格】 主角精疲力竭地跪倒，汗水混着血水滴落地面。远处，警笛声由远及近。

## 六、最终建议（写画面描述时默念）

1. **先有画面，再有文字**：脑子里先像放电影一样过一遍。
2. **动词！动词！动词！** 多用强动词（劈、砸、闪、窜、爆），少用「进行」「做出」等弱动词。
3. **节奏就是生命**：短句造紧张，长句铺氛围。
4. **为你而写**：自己用记关键词即可；给别人/给模型看，务必清晰流畅。
