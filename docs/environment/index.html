本地预览文档站

cd /Users/qy/CodeBuddy/Claw
python3 -m http.server 8788 --directory docs

然后打开 http://127.0.0.1:8788/。页面链接全部使用相对路径，直接从子目录起服务或部署到 GitHub Pages 项目子路径都能正常跳转。

资源纪律预览服务是轻量静态服务，用完即停；打碟（Pioneer DJ）时不要启动任何后台重进程，也不要自动拉起网关、模型服务或训练任务。

GitHub Pages 发布

仓库已配置 Pages 工作流：推送 main 且 docs/** 有变更时自动部署 docs/ 目录。

  1. 把 docs/ 提交并推到 origin/main。
  2. 在仓库 Settings → Pages 里把 Source 设为 GitHub Actions（工作流文件在 .github/workflows/pages.yml）。
  3. 工作流跑完后得到 https://cyq87999-oss.github.io/Claw/ 形式的地址。

因为站点零构建、零依赖，也可以在 Settings → Pages 里直接选 main + /docs 发布，不需要装 MkDocs 或 Node。
