逐镜剧本与情绪弹簧

这一层负责把剧情拆成镜，输出本镜剧情；下一层再把每镜剧情写成 8 行一镜到底提示词。不要在拆镜阶段写运镜参数。

固定字段

镜号|景别|画面动作|台词|情绪
  • 每个镜号一行，格式统一，不写镜头外散文、不总结、不复述规则。
  • 台词单句不超过 15 字，口语化；单集台词总量 200–300 字。
  • 单集 45–50 镜 / 90–120 秒。

情绪弹簧

段落作用
0–3s强钩，先给承诺
5–40s压：憋屈、危机，只攒不放
40–75s放：一个主峰值，爽度＝憋住总量 × 合理代价
75–90s留扣，开下集问题

单集只设一个主峰值，不靠连续反转刷量。

信息差与尾钩

  • 上集未解之谜，本集开头必须「回收＋开新扣」。
  • 尾钩在信息 / 关系 / 身份 / 选择四类里轮换，禁车祸、偷听、空降。
  • 付费卡点卡在「故事承诺清晰、情感问题未解」处，用揭示型悬念，不用截止型。

景别有戏

  • 全景给孤独与命运，近景给语言交锋，特写只留关键转折当标点。
  • 仰拍强势、俯拍卑微，人物纵向位置即权力关系。

图生视频字段

需要把参考图转成视频节点时，按下列字段补齐，字段只服务于这一镜：

主体：（外貌 / 服装 / 位置 / 朝向）
动作：（幅度 / 方向 / 速度）
镜头运动：（推拉摇移跟升降旋转）
景别构图：竖屏 9:16，主体居中 / 三分线，头顶留白
光影氛围：（光源 / 色调 / 时间天气）
风格一致性：（画风 / 材质 / 质量词）
节奏时长：X 秒内完成
空间关系：前景，中景，背景
首尾帧：首帧；尾帧
负面提示词：避免模糊、变形、多余肢体、字幕水印
两层不要混这是拆镜与图生视频节点用的字段表；成品一镜到底提示词只走 8 行规格，不套这些字段前缀。

输出顺序

  1. 人物小传：每角色 3 句（擅长 / 痛 / 藏）。
  2. 逐镜剧本：按固定字段逐镜输出。
  3. 下集钩子：一句。
