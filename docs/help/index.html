常见问题

按「先看页面、再看服务、最后看缓存」的顺序排查，别一上来重装环境。

页面还有旧提示词 / 乱码

现象：还能看到全局常量层、风格预设、方括号标签、港风武侠格式卡之类的旧文本。

  1. 先看版本标识：新页面顶部有 v2 已清理 · 8 行规格 · 旧技术标签全部移除。没有就是加载了旧页面。
  2. 再看 URL：用带版本参数的地址强制刷新，例如 /index.html?v=20261109v2。
  3. 再核对服务端文件：用 curl 拉下页面搜旧字符串，确认服务返回的内容不是另一份副本。
  4. 最后清本地：清站点缓存与 localStorage；本地缓存只恢复剧情，不恢复提示词。
页面已加禁缓存入口 HTML 带 Cache-Control: no-store 与 Pragma: no-cache 的 meta，正常情况下刷新即拿新页。

刷新后还是旧页

  • 确认打开的是 /index.html 而不是别的副本；/ 默认映射到 prompt_studio.html。
  • 技能目录里存在多份工作台副本，但 8771 服务的静态根是 Desktop，只有 Desktop 下的文件会被访问到。
  • 用带查询参数的新 URL 区分缓存，不要反复按同一个刷新键。

批量生成太卡

  • 批量生成改为分批串行，每 8 镜让出一次主线程，点按钮可随时停止。
  • 卡片按需绘制，不在视口内的卡片不参与渲染。
  • 一次别生成上百镜；先跑 8 镜验证输出格式，再续跑。

缓存把旧提示词带回来了

本地缓存恢复时只保留 title、story、每镜 beat，prompt 一律清空。旧格式提示词不会被回填到卡片上。

模型连不上 / 生成无返回

  1. 确认 8771 服务在跑，页面能打开。
  2. 查 curl -s http://127.0.0.1:8771/ollama/api/tags，以实际返回的模型列表为准。
  3. 2026-11-06 本地模型权重曾被误删、连接断线，未明确恢复前不要按旧清单假设，也不要擅自重新下载或重启。
