生成工具总览

仓库里有几套并行的创作工具。先按任务选一套，不要同时全开。

花夕 Web 视频生成器

huaxi/ 面向 Web 端的视频生成器，默认可灵 provider；火山、阿里不作为默认接入。

  • 适合：已有成品提示词，要直接发起图生视频 / 文生视频。

幕匠创作导演

mujiang/ 覆盖编剧策划、分镜设计、出图、视频生成、ffmpeg 剪辑合成的全流程，默认走 xjai（OpenAI 兼容）provider。

  • 适合：从剧本到成片一条链跑完，需要规范化分镜与工作流模板。

短剧自动化工厂

auto-drama/ 全自动短剧量产流水线，另有 manju_pipeline/ 作为漫剧管线。

  • 适合：批量出片；使用前先确认流水线当前是否有产出，避免空跑。

ComfyUI 与锁脸

ComfyUI/、lora-studio/ 负责本地出图与角色一致性。已确认的路线：

  • 人物锁脸靠为每个主角训练专属角色 LoRA，IPAdapter / seed 锁不住。
  • learnings/ 已 clone 官方 IPAdapter 仓库，含 22 个现成工作流；需 ViT-H，weight 约 0.8，多参考图取 average。
  • 本地训练与出图路线曾暂停，出图 / 图生视频改用云端积分。
长任务纪律批量出图须后台常驻、支持断点续跑、跑完自检；出片优先，绝不删模型素材；跑完即关 ComfyUI，别留后台重进程。

接入前先定规格

无论走哪套工具，送到视频模型的成品提示词都按 8 行一镜到底规格 产出；工具只负责发起任务，不负责改写提示词格式。
